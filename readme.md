# PayUp

A simple command-line Python application for calculating a bill total
(plus tip), divided between multiple people to calculate the bill person.

## Features

- Enter name
- Enter event name
- Enter the bill amount
- Enter the tip percentage
- Enter the number of people sharing the bill
- Calculate each person's contribution
- Display the result 

## Technologies

- Python 3

## How to Run

Download & run the program from the terminal:

```bash
python pay_up.py
